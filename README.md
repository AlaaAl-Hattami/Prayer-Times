# ⏰ **Prayer-Times-API**

**Prayer-Times-API** is a RESTful API that provides accurate prayer times for different locations around the world. It allows you to retrieve prayer times (Fajr, Dhuhr, Asr, Maghrib, Isha) based on city, country, or geographic coordinates. The API supports multiple calculation methods and includes functionality for both Muslim prayer times and Iqama times.

---

## 🔍 **Key Features:**

- 🌍 **Global Prayer Times**: Retrieve prayer times for any city, country, or geographic coordinates.
- 📅 **Multiple Calculation Methods**: Supports different methods for calculating prayer times (e.g., ISNA, Umm al-Qura, MWL).
- 🕋 **Accurate Iqama Times**: Get Iqama times for prayer.
- 💡 **Flexible Time Formatting**: Prayer times can be returned in different formats (24-hour, 12-hour, etc.).

---

## 💻 **Technologies Used:**

- **Backend**: JavaScript (Node.js with Express)
- **Data Source**: Calculation methods from multiple sources
- **API**: REST API
